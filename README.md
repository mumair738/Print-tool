# Smart Cyber Cafe - Quick Print Utility

Ye tool **Smart Cyber Cafe & Mobile Zone (Khetasarai, Jaunpur)** ke liye banaya gaya hai jisse aap WhatsApp screenshots aur IDs ko instantly crop, rotate aur A4 size par perfectly print kar sakein, aur 3.2cm x 4.2cm ki passport photos ka 6-pcs grid (5px border ke sath) bina kisi page wastage ke print kar sakein.

### Kaise Use Karein:
1. `index.html` file ko apne browser (Chrome/Edge) me double-click karke open karein.
2. **Crop & Print Doc** tab me WhatsApp screenshots ya documents upload karke crop/rotate karke print karein.
3. **Passport (3.2x4.2cm)** tab me individual passport photo upload karke A4 sheet par 6 photos direct print karein.
